# nafs-pro - منصة تدريب نافس

## الملفات
- index.html  : دخول وتسجيل الطلاب
- config.js   : إعدادات Supabase (عدّله قبل الرفع)
- css/style.css : التصميم والخلفية المتحركة
- sql/01_schema.sql : الجداول والأمان (يُنفَّذ في Supabase SQL Editor)

## الخطوات
1. أنشئ مشروع Supabase ثم نفّذ sql/01_schema.sql
2. ضع Project URL و anon key في config.js
3. ارفع المجلد إلى مستودع GitHub باسم nafs-pro
4. فعّل GitHub Pages: Settings > Pages > Branch: main
